Actualizar la base de datos

Toca el botón, ve a Supabase y pega.

  1. Toca Copiar todo (arriba).
  2. Abre Supabase → tu proyecto → SQL Editor (ícono >_) → + New query.
  3. Deja el dedo presionado en el cuadro vacío → Pegar.
  4. Toca Run. Si sale un aviso, toca Run this query.
  5. Listo cuando diga Success. No rows returned.

Esto no borra nada de tus datos; solo agrega lo nuevo y actualiza las reglas. Se puede correr las veces que quieras.
